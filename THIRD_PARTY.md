## Inspecting or replacing libraries

On Linux, run the AppImage with `--appimage-extract` to obtain its directory tree. Third-party notices, the Ubuntu inventory, Debian notices, common licenses and wheel metadata are under `squashfs-root/usr/share/doc/tingsu/third-party/`. The editable directory can be launched with `squashfs-root/AppRun`. The runtime libraries and Qt shared objects are under `usr/lib/tingsu/`. The build scripts assemble and package this layout. [Linux build instructions](packaging/linux/README.md)

The Windows executable extracts its Qt shared libraries, external tools and collected license files at launch. Its embedded notices are under `licenses/`, including `licenses/ffmpeg/LICENSE` and `licenses/codex/NOTICE`. The archive can be inspected with PyInstaller's `pyi-archive_viewer`. Modified libraries can also be installed in a Windows Python environment and repackaged using the supplied PyInstaller specification. [Windows build instructions](packaging/windows/README.md) · [PyInstaller archive tools](https://pyinstaller.org/en/stable/advanced-topics.html#using-pyi-archive-viewer)
