# Third-party software and source downloads

The Tingsu application source uses the license in [LICENSE](LICENSE). The distributed desktop runtimes contain independently licensed components. The following locations supply source code and the notices for the released x86_64 builds.

| Component | Distribution and upstream source |
| --- | --- |
| Linux desktop shell | Tingsu's C++ window uses the system GTK 3, JSON-GLib and WebKitGTK libraries. The distribution supplies and updates its WebKit and JavaScriptCore engine. [GTK](https://www.gtk.org/) · [WebKitGTK](https://webkitgtk.org/) |
| Windows desktop shell | Tingsu's Win32 C++ window hosts the system Microsoft Edge WebView2 Evergreen Runtime using the Microsoft WebView2 SDK loader. The loader distribution terms accompany the package. [WebView2 SDK](https://www.nuget.org/packages/Microsoft.Web.WebView2/1.0.2903.40) · [Evergreen Runtime distribution](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/distribution) |
| Linux multimedia and system libraries | Ubuntu 22.04 provides FFmpeg 4.4.2 (Ubuntu package 7:4.4.2-0ubuntu0.22.04.1), Python 3.10, GStreamer, PulseAudio, ALSA and other runtime components. The inventory maps the build environment's 411 binary packages to their versioned Ubuntu source records, including distribution patches. Each record links its source files. ## Inspecting or replacing libraries

On Linux, run the AppImage with `--appimage-extract` to obtain its directory tree. Third-party notices, the Ubuntu inventory, Debian notices, common licenses and wheel metadata are under `squashfs-root/usr/share/doc/tingsu/third-party/`. The editable directory can be launched with `squashfs-root/AppRun`. The bundled multimedia runtime libraries are under `usr/lib/tingsu/`. The build scripts assemble and package this layout. [Linux build instructions](packaging/linux/README.md)

The Windows executable extracts its Python runtime, desktop shell, media tools and collected license files at launch. Its embedded notices are under `licenses/`, including `licenses/ffmpeg/LICENSE`. The archive can be inspected with PyInstaller's `pyi-archive_viewer`. Modified libraries can also be installed in a Windows Python environment and repackaged using the supplied PyInstaller specification. [Windows build instructions](packaging/windows/README.md) · [PyInstaller archive tools](https://pyinstaller.org/en/stable/advanced-topics.html#using-pyi-archive-viewer)
